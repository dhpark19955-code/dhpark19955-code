## 지수 편입·편출 트래커 - 어떻게 만들었나

**문제.** 지수 정기변경일에 패시브 자금이 정해진 종가에 일제히 매매하는데, 어느 종목이 들어오고 나가는지는 지수마다 규칙이 다르고(산업군 비중·버퍼·시장 커버리지·위원회 재량) 판단에 필요한 데이터는 유료 단말이나 로그인벽 뒤에 있습니다.

**접근.**
1. **규칙을 원문에서 옮김** - KOSPI200 의 산업군 내 누적 85%·110%/90% 버퍼(인원 반올림), MSCI 의 편입 1.5C · 유지 2/3C, Nasdaq-100 의 11월 말 순위와 101~125위 버퍼 자격, S&P 500 의 GAAP 흑자·유동비율 요건.
2. **비공개 값만 근사·역산** - MSCI 기준선 C 는 증권사 편입선에서 역산하고 밴드 밖은 '경합'으로 강등, KOSPI200 산업군은 신·구 두 분류 체계가 같은 판정일 때만 '유력'.
3. **데이터는 전부 무료 공개 소스** - ETF 보유종목 공시(과거 날짜 조회로 백테스트), 거래소·포털 API, DART, SEC XBRL. 막힌 경로(KRX 로그인벽, 지수사 봇 차단)는 우회하지 않고 대체 소스를 실측해 채택.
4. **백테스트로 틀린 지점을 찾고 원문으로 고침** - KOSPI200 6월 재현은 단순 시총순위 모델 오판 18건에서 방법론 구현 후 1건으로. Nasdaq-100 미적중 1건(BIIB)이 버퍼 자격 규칙을 드러내 모델에 반영.
5. **판정을 아이디어로** - 편입 유력·편출 유력·경합 그룹을 관심종목으로 자동 등록해 등록 후 수익률, 벤치마크 초과분, 발표일 D-day 를 한 표에서 추적. 편입 후보가 발표 전에 이미 올라 있다는 관찰이 "발표 뒤 리밸런싱일까지의 구간을 따로 보자"는 다음 질문으로 이어짐.
6. **배포는 Excel·Google Sheet 에서 정적 HTML 로** - 공개용은 `index.html` + `data.json` 하나로 공식 발표 대조, 예측 스냅샷, 백테스트, 일정 D-day 를 보여 줌.

**검증.** 발표가 나올 때마다 공식 명단을 `official_changes.csv` 에 넣으면 적중 대조표가 다시 만들어집니다. 2026-11-18 KOSPI200 발표는 '유력' 9건 중 8건 적중, MSCI 11월 리뷰는 변경 없음이었고 유력으로 잡았던 1건은 "MSCI 개별 판단으로 가능성 낮음"이라 메모해 둔 사례였습니다. 적중과 미적중을 똑같이 기록합니다.

## 일하는 방식

- **숫자와 줄글을 분리** - 데이터셋 xlsx 는 숫자만(파랑 입력·검정 수식·초록 링크), 원문은 front matter 를 붙인 md 아카이브로
- **소스마다 다른 정의를 통일** - 시총은 상장주식수 × 정규장 종가, 분기 손익은 3개월치, 2차 출처는 1차와 대조 전엔 쓰지 않음
- **자동 검출 → 사람이 확정** - 항등식·비율 범위·배수 역산으로 걸러낸 것만 원문과 대조. IR 수치는 문장+출처로 뽑고 사람이 표에 넣음
- **공식 원문 우선, 틀리면 원문으로 고침** - 지수 규칙·회계 정의는 방법론 원문에서 가져오고, 백테스트가 틀린 지점을 보여 주면 데이터가 아니라 규칙 해석부터 다시 봄
- **보고는 "확인한 것 / 못 한 것 / 정정한 것"** - "안전합니다"로 끝내지 않음
- **막히면 우회하지 않음** - 로그인벽·봇 차단은 공개 대체 출처로, 키는 환경변수로만, 리포트·전문은 재배포하지 않음
