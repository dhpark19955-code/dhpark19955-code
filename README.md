# 상장사 재무·공시 데이터를 코드로 모으고, SQL과 Excel로 검증합니다

투자 검토에 쓰는 숫자를 **API·공시 원문·IR 덱·컨퍼런스콜 전문·증권사 리서치**에서 한 번에 모아, 검산을 통과한 데이터셋으로 만드는 작업을 기록합니다. 국내(DART·KRX·네이버)와 해외(SEC EDGAR·Yahoo) 상장사를 같은 규칙으로 다룹니다.

두 저장소는 한 쌍입니다. 종목 하나를 파는 파이프라인에서 나온 규칙(분기 3개월·같은 계정 안에서만 차분·한 연도 한 보고서·최신 접수번호 우선)을 그대로 200사 유니버스에 옮겼고, 겹치는 종목은 두 파이프라인이 같은 숫자를 내는지 교차검증했습니다.

## 일하는 방식

- **숫자와 줄글을 분리** - 데이터셋 xlsx 는 숫자만(파랑 입력·검정 수식·초록 링크), 원문은 front matter 를 붙인 md 아카이브로
- **소스마다 다른 정의를 통일** - 시총은 상장주식수 × 정규장 종가, 분기 손익은 3개월치, 2차 출처는 1차와 대조 전엔 쓰지 않음
- **자동 검출 → 사람이 확정** - 항등식·비율 범위·배수 역산으로 걸러낸 것만 원문과 대조. IR 수치는 문장+출처로 뽑고 사람이 표에 넣음
- **보고는 "확인한 것 / 못 한 것 / 정정한 것"** - "안전합니다"로 끝내지 않음
- **막히면 우회하지 않음** - 로그인벽·봇 차단은 공개 대체 출처로, 키는 환경변수로만, 리포트·전문은 재배포하지 않음
